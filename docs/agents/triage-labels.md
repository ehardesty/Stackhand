# Triage labels

| Skill role        | GitHub label       | Meaning                                 |
| ----------------- | ------------------ | --------------------------------------- |
| `needs-triage`    | `needs-triage`     | A maintainer must evaluate the issue    |
| `needs-info`      | `needs-info`       | More information is required            |
| `ready-for-agent` | `ready-for-agent`  | The issue is ready for an agent          |
| `ready-for-human` | `ready-for-human`  | The issue requires human implementation |
| `wontfix`         | `wontfix`          | The issue will not be implemented        |

When a skill names a triage role, use the matching GitHub label.
